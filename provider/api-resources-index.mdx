This page is the catalogue of every Jersey resource class that participates in the Fineract REST surface. `JerseyConfig` (see [Jersey bootstrap](/provider/jersey-bootstrap)) does not maintain a hand-curated list — it walks the Spring context after refresh and registers **every** bean annotated `@jakarta.ws.rs.Path`. Adding a class with `@Path` to the classpath (and making it a Spring bean) is enough to put new endpoints on the wire.

The 111 classes below were found by:

```bash
find fineract-provider/src/main/java -name '*ApiResource.java' | wc -l
# 111
```

Every row links to the source file (relative to `fineract-provider/src/main/java/`) and shows the **class-level** `@Path` — that is, the root that all `@GET`/`@POST`/`@PUT`/`@DELETE` methods on the class are nested under. Sub-paths defined on individual methods (e.g. `@Path("{loanId}/charges")`) are not enumerated here; for those, consult the resource class directly or the generated `fineract.json` OpenAPI document.

<Note>
  The companion `BatchApiResource` (`/v1/batches`) lives in the `fineract-core` module, not in `fineract-provider`. It is still registered through the same `JerseyConfig` because the component scan covers `org.apache.fineract.**`. It is documented here as well because, from the wire perspective, it is a peer of the resources below.
</Note>

## Commonly-used resources — method excerpts

The catalogue above is uniform but the heaviest endpoints are worth seeing inline. The signatures below are taken verbatim from the source (with whitespace normalised). They are **not** exhaustive — `LoansApiResource` alone has 30+ methods. Use these as a navigation aid; the full surface lives in the source file or in the generated OpenAPI spec.

### `BatchApiResource` — `/v1/batches`

In `fineract-core/src/main/java/org/apache/fineract/batch/api/BatchApiResource.java`:

```java
// Class
@Path("/v1/batches")
// One method, dispatches every internal CommandStrategy
@POST
public Response handleBatchRequests(@QueryParam("enclosingTransaction") final boolean enclosingTransaction,
                                    final String requestBody);
```

See [Batch API](/batch/overview) for how `BatchApiService` fans the strategies out.

### `ClientsApiResource` — `/v1/clients`

```java
@GET @Path("downloadtemplate")
@Produces("application/vnd.ms-excel")

```

See [Clients API](/api/clients-api).

### `LoansApiResource` — `/v1/loans`

`LoansApiResource` is the largest single resource in the codebase. Selected methods:

```java
@GET @Path("{loanId}/template")
@Produces({ MediaType.APPLICATION_JSON })
@ApiResponses({ @ApiResponse(responseCode = "200", description = "OK",
        content = @Content(schema = @Schema(
                implementation = LoansApiResourceSwagger.GetLoansApprovalTemplateResponse.class))) })
public String retrieveApprovalTemplate(@PathParam("loanId") ... );

@GET @Path("downloadtemplate")
@Produces("application/vnd.ms-excel")
public Response getLoansTemplate(@QueryParam("officeId") ... );

@GET @Path("glimAccount/{glimId}")
@Produces({ MediaType.APPLICATION_JSON })
public String getGlimRepaymentTemplate(@PathParam("glimId") ... );

@GET @Path("repayments/downloadtemplate")
@Produces("application/vnd.ms-excel")
public Response getLoanRepaymentTemplate(@QueryParam("officeId") ... );

@POST @Path("uploadtemplate")
@Consumes(MediaType.MULTIPART_FORM_DATA)
@RequestBody(description = "Upload Loan template",
```
